# Mhirex 1.0-beta8 (pre-release)

This is a **pre-release** build for testing, not a statement of production readiness or licence
compliance.

## What is in this build

- Rebranded to **Mhirex** (`com.mhirex.editor`). The application ID changed from LibreCuts, so this
  is a separate app: it cannot upgrade an existing LibreCuts install, and prior LibreCuts projects
  and settings are not migrated or reachable.
- Optional **Sign in with Google** profile. It is not required to edit, import or export anything.
  The stored profile and cached avatar stay on the device; there is no Mhirex server.
- Release APKs are signed with the project release key.

## Known limitations in this build

- **Google Sign-In has not been tested with a real Google account.** The code compiles and the
  credential configuration is present, but no sign-in, avatar download or sign-out has been
  exercised on a device. Please treat it as unproven until you have tried it.
- Device testing has only been run on an **API 36** emulator. API 29, 33 and 34 are not yet
  verified.
- The bundled `filter_preview_*.jpg` and `trans_preview_*.webp` assets do not yet have documented
  provenance.

## Licence and source availability — incomplete

Mhirex bundles `ffmpeg-kit-full-gpl`, which is licensed under GPL-3.0. **The GPL disclosure work is
not complete in this build.** The in-app AboutLibraries entry, the packaged GPL licence text and
the corresponding-source offer still need to be added.

This release therefore **does not claim to be GPL-compliant**, and must not be represented as
satisfying GPL distribution obligations. Those obligations need to be completed before a public
or Play Store distribution. LibreCuts/MIT attribution from the upstream project is retained in the
app and repository.
